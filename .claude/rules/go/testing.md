# Go のテスト規約

## 実 AWS を呼ばない

テストはフェイクで行う。

フェイクの置き場所は用途で決める。

- `s3test/fake.go` のように別パッケージへ出す — 他パッケージからも使う想定があるとき
- `fake_test.go` としてパッケージ内に閉じる — そのパッケージ内で完結するとき

`var _ pkg.API = (*Fake)(nil)` を書いておくと、インタフェースの変更にフェイクが追従していないことをコンパイル時に検出できる。

## 課金 API は記録・再生

Textract と Bedrock は課金が発生する。**実 API を呼ばず、記録済みレスポンスの再生で検証する。**

記録・再生はインタフェース境界のデコレータとして実装する。

- `Recorder` は実 API を通しつつレスポンスを溜める
- `Replayer` は記録から返す
- どちらも `API` (Bedrock は `Converser`) を満たすため、`New(replayer)` と差し替えるだけで、ページング畳み込みやリトライを含めた経路全体を実 API なしで検証できる

記録は `backend/testdata/{textract,bedrock}/` に置く。

**実レスポンスでない記録には `note` フィールドでその旨を明記する。**
手書きや合成のフィクスチャを実物と誤認すると、通っているテストが何も保証しなくなる。

## 実時間を待たない

指数バックオフのテストで実待機しない。`Sleeper` を差し替える。

乱数も `WithRandN` で差し替え、下限・中央・上限を決定的に検証する。

## 外部バイナリに依存するテスト

CI にバイナリが無い可能性がある。`exec.LookPath` で不在を検出したら `t.Skip` する。

バイナリ非依存の純ロジック (パスの整形、出力のパース、エラー分類) は常時実行されるように分けて書く。

## テストの主張が空振りしていないか確かめる

テストを書いたら、**検証対象を意図的に壊して落ちることを確認する。**

固定桁のタイムスタンプが辞書順を保つことを検証するテストで、値の選び方によっては可変桁フォーマットでも偶然通ってしまう、という例が実際にあった。
通ることだけを確認したテストは、何も検証していない可能性がある。

## テストデータの置き場所

| 置き場所                   | 内容                             |
| -------------------------- | -------------------------------- |
| 各パッケージの `testdata/` | そのパッケージ内で完結するデータ |
| `backend/testdata/`        | 記録済み AWS レスポンス専用      |

`backend/testdata/pdf/` は arXiv 由来で再配布不可のため git 管理外。
テスト用の PDF が必要な場合は実行時に自前生成する。
