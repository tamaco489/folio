  • 全体: comparison.json の status。REVIEW_PENDING は needsReview: true (どちらかの経路が verify でレビュー要、または欠落ページあり)
  • 実行時間: Step Functions の実行の startDate → stopDate

  • 題名 / 著者 / 要旨の一致: diff.title.equal など (正規化後の完全一致)
  • コスト: 07 の算出式 (Textract のページ数 × 単価 + Bedrock のトークン数 × 単価)
