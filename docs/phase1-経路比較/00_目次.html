02結論の要約
  • 5 本すべてで経路 A は完走し、経路 B は 4 本で全ページ、1 本 (二段組) で 12 ページ中 11 ページが揃った (04)
  • 経路 B は当初 4 本中 3 本で JSON が壊れて途中停止した (引用符のエスケープ漏れ)。tool use で受け取る修正 (#111) の後は引用符では壊れなくなったが、型の崩れ (配列が文字列で返る) が 1 ページ残った (09)
  • コストは設計時の「A が安価」という想定と違い、完走した論文ではほぼ同額で B がやや高い。A は Textract (Tables の課金) が 5〜7 割を占める (07)
  • 信頼度は経路 A で title か tables が最低、経路 B は sections が最低で tables はほぼ 1.0 だった。ただし B の tables の信頼度は原本照合だけで、構造の正しさは測っていない (08)
