差分の内訳

見出し・節・表・図・参考文献ごとに、両経路で何がどう違ったか (抜粋つき)

採用した実行 (03) の result-textract.json (経路 A) と result-bedrock.json (経路 B) を、原本 (pdftotext の出力とページ画像) と突き合わせた。抜粋は原文のまま (訳さない)。件数や文字数は JSON から機械的に数えたもので、「原本と一致」と書いた箇所は原本の該当行を目視で確認した。確認していない範囲は各節の末尾に書く。

07書誌 (題名・著者・要旨)

題名と著者は 5 本すべてで両経路が一致 (正規化後)。要旨は 2 本で一致し、3 本は A の行末ハイフン (accu- rately) や en dash の違い (forgetting-utility vs forgetting–utility) で不一致。2608.20318v1 の A は要旨に SO that (原本 so that) があるが、比較が大文字小文字を無視するため一致扱いになっている。著者の所属は A が所在地まで取り、B が省略する傾向 (2608.20338v1)。2608.20318v1 では 2 つの所属の対応を両経路とも正しく分けられていない (A は Einsia.A と末尾が欠け、B は 10 名全員に 2 所属を連結)。
